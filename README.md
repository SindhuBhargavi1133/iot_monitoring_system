## IoT Temperature and Humidity Monitoring (Mini Project)
This repository contains my IoT temperature and humidity monitoring mini-project, including documentation, screenshots, and sample code.
- Documentation: [IoT-Project.pdf](IoT-Project.pdf)
- Screenshots: See /screenshots

## How it works
This mini project demonstrates real-time temperature and humidity monitoring and alerting using virtual tools (Wokwi, ThingSpeak), with no hardware required.
